== Description ==

Transform your WooCommerce store into a complete catalog by hiding prices and purchase buttons while adding professional product inquiry forms.

= Key Features =
- Completely disable purchasing functionality
- Replace Add to Cart buttons with inquiry forms
- Customizable inquiry form with email notifications
- Flexible button positioning options
- Works with both simple and variable products
- Mobile-friendly responsive design

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/catalog-mode-product-inquiry-for-woocommerce` directory
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Configure settings under WooCommerce > Catalog Mode Settings

== Frequently Asked Questions ==

= Can customers still see prices? =
Yes, prices remain visible by default. You can hide them using custom CSS.

= Does this work with variable products? =
Yes! The plugin fully supports product variations.

= Can I customize the inquiry form fields? =
Absolutely. All form fields can be modified through the settings page.
