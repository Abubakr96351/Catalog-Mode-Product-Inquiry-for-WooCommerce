Convert WooCommerce into a catalog by hiding Add to Cart buttons and enabling product inquiries.

== Description ==
This plugin adds catalog mode functionality to **WooCommerce** stores, replacing purchase options with inquiry forms.
Complete WooCommerce catalog solution that:
- Hides all purchase functionality
- Adds customizable inquiry forms
- Works with all product types
- Fully responsive design

= Features =
- Multiple button position options
- AJAX form submission
- Email notifications
- Variation support

== Installation ==

1. Upload the plugin to /wp-content/plugins/
2. Activate through WordPress admin
3. Configure under Settings > WC Catalog Mode

== Frequently Asked Questions ==

= Can I use this with variable products? =
Yes! The plugin fully supports variable products and will capture variation selections.
